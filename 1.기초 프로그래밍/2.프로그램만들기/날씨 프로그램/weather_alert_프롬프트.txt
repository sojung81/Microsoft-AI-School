Python 날씨·온습도·미세먼지 대시보드 개발 통합 프롬프트
대상 파일: weather_alert.py

아래는 처음 요청한 온습도 알리미부터 이후에 추가한 화면 디자인, 그래프, 날씨·미세먼지, 배경 애니메이션, 지역 선택 요구사항을 합친 최종 개발 요청이다. 초기 요청과 이후 요청이 다를 때는 아래에 정리한 최신 요구사항을 우선한다.

너는 내 Mac과 VS Code 환경에서 Python 프로그램을 직접 구현하고 실행을 확인하는 개발 도우미다. 아래 요구사항에 맞게 프로젝트 파일을 만들거나 수정해 줘. 설계 설명만 하지 말고 실제로 사용할 수 있도록 구현하고, 가능한 범위에서 직접 테스트해 줘.

1. 프로젝트 목적과 사용자 수준

- Python으로 외부 날씨 API의 데이터를 수집하고, JSON·CSV로 저장하며, 조건에 따라 macOS 알림을 보내는 프로그램을 만들고 싶다.
- 나는 if, for, while, 함수 등 Python 기초 문법을 배우는 초보자다.
- 주요 코드에 초보자가 이해할 수 있는 한국어 주석을 작성해 줘.
- 데이터 수집 코드와 화면 코드는 분리하고, 전체 동작 원리를 README에서 설명해 줘.
- 최종 결과물은 터미널에 숫자만 출력하는 형태가 아니라, 예쁘게 볼 수 있는 별도 프로그램 창이어야 한다.

2. 개발 환경과 설치 원칙

- 운영체제: macOS, Apple Silicon.
- 개발 도구: VS Code.
- 언어: Python.
- 기존에 라이브러리 설치 위치와 실행 환경 문제를 겪었으므로, 작업 전에 현재 VS Code에서 선택된 Python 인터프리터를 확인해 줘.
- 이 프로젝트에서 확인했던 인터프리터는 /usr/local/bin/python3, Python 3.14.6이었다. 실제 작업 시에는 다시 확인해 줘.
- 불필요한 외부 패키지를 설치하지 말고 가능한 Python 기본 라이브러리를 사용해 줘.
- 기존 설치 환경을 활용하고, 새로 설치해야 하는 것이 있으면 이유를 알려줘.
- 현재 프로젝트 폴더: /Users/sojung/Desktop/microsoft AI school/weather-alert
- 기존 실습 파일과 이미 수집한 데이터를 보존해 줘.

3. 실행 방식

- VS Code에서 weather_alert.py를 열고 오른쪽 위 Run을 누르면 대시보드 창이 바로 떠야 한다.
- 매번 긴 명령어나 단축키를 외워서 입력하지 않아도 쉽게 실행할 수 있게 해 줘.
- 실행 즉시 데이터를 한 번 수집하고, 프로그램이 실행 중인 동안 1분마다 자동 갱신해 줘.
- 최초 요청에서는 10분 주기였지만 이후 1분으로 변경했으므로, 최종 주기는 60초다.
- 수동 새로고침, 자동 갱신 일시정지, 다시 시작 기능을 넣어 줘.
- 인터넷 요청 때문에 프로그램 창이 멈추지 않도록 처리해 줘.
- 창 닫기와 터미널의 Control+C로 안전하게 종료할 수 있게 해 줘.
- 1분을 기다리지 않고 한 번만 수집하는 테스트 기능도 유지해 줘.

4. 날씨 API와 수집 항목

- 기본 API는 무료이며 API Key가 필요 없는 Open-Meteo를 사용해 줘.
- HTTP GET 방식으로 JSON을 요청하고 필요한 값을 추출해 줘.
- 기본 지역은 서울이지만 다른 지역도 선택할 수 있어야 한다.
- 현재 온도, 상대습도, 데이터 기준 시각, 프로그램의 수집 시각을 구분해 줘.
- 맑음, 구름, 흐림, 안개, 비, 소나기, 눈, 뇌우 등의 날씨 상태를 한국어로 보여줘.
- 체감온도, 바람, 강수량, 적설량 등 함께 보면 유용한 정보도 보여줘.
- 미세먼지 PM10과 초미세먼지 PM2.5도 가져와 줘.
- 필요한 경우 Open-Meteo의 별도 대기질 API를 사용해 줘.
- 기상 자료와 대기질 자료는 기준 시각과 갱신 주기가 다를 수 있으므로 각각 구분해서 표시해 줘.
- 수치의 단위를 명확하게 표시해 줘. 기온은 °C, 습도는 %, 미세먼지는 µg/m³ 등이다.
- 미국 AQI를 표시한다면 미국 기준임을 명시하고 국내 등급과 혼동하지 않게 해 줘.
- 없는 데이터는 0으로 꾸미지 말고 확인 불가나 대시로 표시해 줘.
- 1분은 조회 주기이며 원본 기상값이 매분 바뀐다는 뜻은 아니라는 점을 안내해 줘.

5. 저장 파일과 기록 보존

- weather_latest.json: 마지막으로 수집한 최신 데이터로 갱신해 줘.
- weather_history.csv: 수집 시각과 함께 과거 기록을 계속 누적해 줘.
- 데이터 파일은 스크립트와 같은 프로젝트 폴더에 저장해 줘.
- 터미널을 다른 경로에서 실행해도 저장 위치가 바뀌지 않게 해 줘.
- 기존 CSV의 온도·습도 기록은 지우지 말아 줘.
- 날씨·미세먼지 등의 열을 추가할 때는 기존 행을 보존하고, 과거에 수집하지 않았던 항목은 빈칸으로 유지해 줘.
- 실제 수집한 기록과 API가 제공하는 과거 시간별 모델 자료를 구분해 줘.
- 테스트용 가짜 수치를 실제 날씨 기록에 섞지 말아 줘.
- 저장 중 중단되더라도 기존 최신 JSON이 손상되지 않게 처리해 줘.

6. 온도·습도 경고와 macOS 알림

- 온도가 30°C 이상이면 고온 주의 메시지를 출력해 줘.
- 상대습도가 70% 이상이면 습도 주의 메시지를 출력해 줘.
- 경고 기준과 갱신 간격은 코드 상단에서 쉽게 수정할 수 있게 해 줘.
- 조건을 만족하면 macOS 알림 센터에 알림을 표시해 줘. 가능하면 osascript를 사용해 줘.
- 같은 경고 조건이 유지된다는 이유로 매번 동일한 알림을 보내지 않게 해 줘.
- 정상 범위로 돌아왔다가 다시 경고 조건이 되면 새 알림을 보내 줘.
- 알림 상태를 저장해서 재실행이나 지역 변경으로 불필요한 중복 알림이 생기지 않게 해 줘.
- 화면에서 macOS 알림을 켜거나 끌 수 있게 해 줘.
- 실제 경고 조건과 관계없이 알림 기능만 한 번 테스트할 수 있게 해 줘.
- 알림 명령이 성공한 것과 실제 배너가 화면에 표시된 것은 구분해서 설명해 줘.

7. 창 디자인

- Claude처럼 따뜻한 배경과 단정한 카드 구성을 가진 보기 좋은 데스크톱 프로그램으로 만들어 줘.
- 여기서 Claude 형식은 화면 분위기를 뜻한다. Claude 서비스나 API 연동을 요구하는 것은 아니다.
- 상단에 온도, 습도, 날씨, 미세먼지 정보를 나란히 배치해 줘.
- 각 항목 이름은 위쪽에 작은 글씨로 표시하고 현재 값이 잘 보이게 해 줘.
- 자동 갱신 시간은 중요한 정보가 아니므로 큰 카드나 큰 글씨로 강조하지 말아 줘.
- 남은 갱신 시간은 상태줄 등에 작게 표시해 줘.
- 화면이 장식 때문에 복잡해지지 않게 하고 숫자와 그래프를 편하게 읽을 수 있게 해 줘.

8. 온도와 습도 그래프 및 과거 기록

- 최근 온도 그래프를 그려 줘.
- 온도뿐 아니라 습도 그래프도 볼 수 있게 해 줘.
- 온도와 습도를 전환해서 볼 수 있는 버튼을 제공해 줘.
- 과거 데이터도 볼 수 있도록 기간을 선택하게 해 줘. 예를 들어 6시간, 24시간, 48시간, 전체 기록이다.
- 첫 실행에서도 과거 흐름을 볼 수 있도록 API의 과거 시간별 자료를 활용해 줘.
- 직접 수집한 CSV 기록과 API의 과거 모델 자료는 색과 범례로 구분해 줘.
- 그래프에 마우스를 올리면 시각과 값을 확인할 수 있게 해 줘.
- 과거 수집 기록을 표로 볼 수 있게 하고 날짜별로 선택할 수 있게 해 줘.
- 이전에 수집하지 않은 시간을 실제 수집 기록인 것처럼 만들어내지 말아 줘.

9. 날씨에 따른 배경과 애니메이션

- 날씨에 따라 배경색과 분위기가 바뀌게 해 줘.
- 눈이 오는 날에는 옅은 눈송이가 배경에서 부드럽게 떨어지게 해 줘.
- 비가 오는 날에는 보슬보슬한 빗방울이 내리는 느낌으로 표현해 줘.
- 맑음, 구름, 안개 등도 날씨에 맞는 분위기로 표현해 줘.
- 효과는 은은하게 하고 정보 카드나 그래프를 가리지 않게 해 줘.
- 필요하면 움직이는 배경 효과를 끌 수 있게 해 줘.

10. 눈·비 효과 미리보기

- 지금 실제 날씨가 눈이나 비가 아니어도 눈 내리는 모습과 비 오는 모습을 테스트로 보고 싶다.
- 눈과 비를 나란히 볼 수 있는 미리보기 창이나 이에 준하는 기능을 만들어 줘.
- 실제 날씨가 아니라 시각 효과 테스트라는 사실을 명확히 표시해 줘.
- 미리보기 때문에 실제 날씨 카드, API 데이터, 저장 기록이 바뀌면 안 된다.
- 완성 후에는 눈·비 미리보기를 직접 열어서 움직이는 모습을 보여줘.
- 나중에도 쉽게 다시 미리보기를 열 수 있는 버튼을 넣어 줘.

11. 다른 지역 선택

- 서울 이외의 지역도 볼 수 있도록 지역 변경 기능을 추가해 줘.
- 예를 들어 서울, 부산, 인천, 대구, 대전, 광주, 울산, 세종, 수원, 강릉, 제주 등 주요 도시를 선택할 수 있게 해 줘.
- 지역을 바꾸면 해당 지역의 좌표로 온도·습도·날씨·대기질을 조회해 줘.
- 상단 제목, 날씨 카드, 그래프, 기록 표가 현재 선택한 지역을 기준으로 바뀌어야 한다.
- 서로 다른 지역의 기록이 한 지역의 기록처럼 섞여 표시되지 않게 해 줘.
- 지역을 바꾸는 도중 이전 요청이 늦게 도착해도 이전 지역의 값으로 화면을 덮어쓰지 않게 해 줘.
- 처음 선택해 아직 데이터가 없는 지역에는 임시로 확인 불가나 로딩 상태를 표시해 줘.
- 이전 지역의 기록은 삭제하지 말고 지역 정보와 함께 보존해 줘.

12. 오류 처리

- 인터넷 연결이 끊기거나 API 요청이 실패하면 이해할 수 있는 오류 메시지를 보여줘.
- 데이터 일부가 누락되어도 프로그램 전체가 바로 종료되지 않도록 처리해 줘.
- 미세먼지 API만 실패하면 온도·습도·날씨는 계속 보여줘.
- 오류 시 기존 데이터를 보존하고 다음 주기에 재시도해 줘.
- 저장 실패, 알림 실패, 네트워크 실패를 구분해서 알려줘.

13. 파일 구성과 설명

기본 파일은 아래와 같이 구성해 줘.

- weather_alert.py: API 호출, 조건 판단, 파일 저장, 알림, 실행 진입점.
- weather_latest.json: 최신 데이터와 알림 상태.
- weather_history.csv: 누적 수집 기록.
- README.md: 설치 여부, 인터프리터 확인, 실행 방법, 코드 구조, 테스트 범위.

화면과 효과가 복잡해지면 아래처럼 보조 파일로 분리해도 된다.

- weather_dashboard.py: 대시보드 창, 그래프, 지역 선택, 기록 표.
- weather_effects.py: 날씨 배경과 눈·비 애니메이션, 미리보기.
